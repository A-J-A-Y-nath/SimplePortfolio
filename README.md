## How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/A-J-A-Y-nath/SimplePortfolio.git
   cd SimplePortfolio
   ```

2. Open `website/index.html` directly in your browser, or run the local studio:
   - Double-click `start.bat` (or run `node admin/server.js`)
   - Open `http://localhost:8000` in your browser.
